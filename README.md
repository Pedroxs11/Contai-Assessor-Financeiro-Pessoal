# Contai V1

Primeira base funcional Android do Contai, assessor financeiro pessoal.

Inclui:
- Dashboard mobile
- Área do Assessor
- Transações de exemplo
- Fila de confirmação para transações não identificadas
- Categorias livres planejadas
- NotificationListenerService para captura de notificações
- Dados locais na V1
- Arquitetura preparada para Supabase e WhatsApp

Próximas implementações: persistência local real, parser de notificações, deduplicação, motor de confiança, categorias personalizadas, aprendizado das correções, IA, Supabase e WhatsApp.
